# LEPA — Students

## Overview

The Students module stores enrollment, class assignment, and basic profile data.

## Common tasks

### Register / enroll a student
1. Go to **Students → Add student**.
2. Enter full name, date of birth, and guardian contact.
3. Choose **class / section** for the current term.
4. Click **Save**. The student receives a LEPA student ID.

### Transfer a student to another class
1. Open the student profile.
2. Click **Class assignment**.
3. Select the new class and effective date.
4. Save. Historical attendance stays with the old class.

### Deactivate a student
Use **Status → Inactive** (do not delete). Inactive students no longer appear in daily attendance lists.

## Troubleshooting

| Symptom | Likely cause | What to try |
|---------|--------------|-------------|
| Student missing from class list | Wrong term selected, or inactive status | Check term filter; confirm Status = Active |
| Cannot save new student | Required fields empty | Fill name, DOB, and class |
| Duplicate student ID warning | Possible duplicate enrollment | Search by name/DOB before creating |

## Roles
- Teachers: view students in assigned classes
- Admins: create, transfer, deactivate across the school
