# LEPA — Grades

## Overview

Grades (marks) are entered per assessment and published to guardians after the teacher confirms.

## Common tasks

### Enter grades
1. Go to **Grades → Gradebook**.
2. Select class, subject, and assessment (e.g. Midterm).
3. Enter scores for each student.
4. Click **Save draft** (not visible to guardians yet).
5. When ready, click **Publish**.

### Why grades aren’t showing for guardians
Grades remain hidden until **Publish**. Draft scores are teacher-only.

### Fix a wrong score
1. Open the assessment in Gradebook.
2. Edit the student’s score.
3. Save. If already published, click **Publish** again to refresh the parent view.

## Troubleshooting

| Symptom | Likely cause | What to try |
|---------|--------------|-------------|
| Cannot enter scores | Assessment not created, or outside entry window | Ask admin to create/open the assessment |
| Grades missing on parent portal | Still in Draft | Publish the assessment |
| Totals look wrong | Weighting not configured | Check assessment weights under Grades → Settings |
| Student missing from gradebook | Not on class roster | Fix class assignment under Students |

## Roles
- Teachers: enter and publish for assigned subjects
- Admins: configure assessments, weights, and entry windows
