# LEPA — Attendance

## Overview

Attendance is recorded per class period. Teachers mark students present, absent, or late.

## Common tasks

### Take attendance
1. Go to **Attendance → Today**.
2. Select your class and period.
3. Mark each student (default is Present).
4. Click **Submit attendance**.

### Edit attendance after submit
Within the same school day, open the submitted sheet → **Edit** → save again. After the day closes, only an admin can amend.

### View attendance history
**Attendance → Reports → Class history** for a date range.

## Troubleshooting

| Symptom | Likely cause | What to try |
|---------|--------------|-------------|
| Class list empty | No students assigned, or wrong term | Confirm class roster under Students |
| Submit button disabled | Incomplete marks | Mark every student before submit |
| “Already submitted” | Sheet locked for the period | Use Edit if still same day; else contact admin |
| Student not listed | Student inactive or in another section | Check student class assignment |

## Tips
- Take attendance within the first 10 minutes of class when possible.
- Late arrivals: mark **Late**, not Absent, then add a note.
