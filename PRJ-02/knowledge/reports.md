# LEPA — Reports

## Overview

Reports summarize attendance, grades, and enrollment for a term or custom date range.

## Common tasks

### Generate a class grade report
1. Go to **Reports → Grades**.
2. Choose class, subject, and term.
3. Click **Generate**.
4. Download **PDF** or **CSV**.

### Attendance summary
**Reports → Attendance → Class summary**, then pick dates and generate.

### School-wide enrollment report (admin)
**Reports → Students → Enrollment snapshot**.

## Troubleshooting

| Symptom | Likely cause | What to try |
|---------|--------------|-------------|
| Empty report | No published grades / no attendance in range | Confirm data exists; widen date range |
| Generate button disabled | Missing required filters | Select class and term |
| PDF download fails | Browser pop-up blocked | Allow pop-ups for LEPA; try CSV |
| Old data showing | Cached previous run | Click Generate again; hard-refresh the page |

## Tips
- Prefer CSV for spreadsheets; PDF for sharing with leadership.
- Large school-wide reports may take up to a minute — wait for the progress indicator.
